# NumPy — Numerical Computing with Python

A structured collection of NumPy implementations, exercises, and practical experiments covering the core concepts required for scientific computing, data analysis, and machine learning with Python.

## Overview

This repository focuses on developing a strong understanding of **NumPy**, including its array-based computational model, vectorized operations, broadcasting, indexing, mathematical operations, and linear algebra capabilities.

The material is organized to progress from fundamental array manipulation to more advanced numerical computing concepts.

## Topics

* NumPy arrays and array attributes
* Array creation and initialization
* Indexing and slicing
* Boolean indexing and masking
* Reshaping and dimensionality
* Broadcasting
* Vectorization
* Mathematical and statistical operations
* Aggregation functions
* Random number generation
* Sorting and searching
* Copies and views
* Concatenation and splitting
* Linear algebra
* Performance-oriented numerical operations
